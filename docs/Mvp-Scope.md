# Easi-It MVP Scope

## Goal
Build a working system that allows donors, beneficiaries, and vendors to interact with escrow-protected social impact transactions.

---

## Users

### 1. Beneficiary
- Create need requests
- Upload supporting images
- Track request status

### 2. Donor
- View verified needs
- Fund needs
- Track delivery progress

### 3. Vendor
- Accept fulfillment requests
- Deliver goods/services
- Upload proof of delivery
- Withdraw released funds

### 4. Admin
- Verify users and requests
- Approve vendors
- Release escrow funds
- Handle disputes

---

## MVP Features

- User registration (4 roles)
- Need submission system
- Verification workflow
- Vendor listing
- Escrow funding system (logical first, not real payment yet)
- Delivery proof upload
- Admin approval dashboard

---

## NOT in MVP

- Mobile app
- AI recommendations
- Advanced chat system
- Automated payment gateways
- Marketplace scaling features
